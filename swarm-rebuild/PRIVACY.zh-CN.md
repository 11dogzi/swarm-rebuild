# Smart Robot Animation 隐私政策

更新日期：2026 年 11 月 9 日。适用对象：本文件随附的 Smart Robot Animation 扩展代码。

[English](PRIVACY.md) · [使用说明](README.zh-CN.md)

## 项目来源

本项目基于 [DhvanilPatel/swarm-cursors](https://github.com/DhvanilPatel/swarm-cursors) 的 Swarm Rebuild 扩展进行部分逻辑和外观修改。上游 README 另有对 Joel Califa 的 [Swarm](https://github.com/califa/swarm-site) 的致谢。本政策描述的是**当前修改版**，不应被理解为上游项目或其他版本的隐私承诺。

## 本地处理的数据与用途

本扩展没有开发者运营的数据接收服务、账号系统、分析 SDK、广告跟踪或遥测上传功能。当前代码不主动将页面内容、截图或鼠标坐标发送给开发者或第三方服务。

为了实现动画，代码会在浏览器中处理以下信息：

| 信息 | 处理时机与用途 |
| --- | --- |
| 最近一次鼠标位置 | 鼠标追踪脚本会在浏览器允许注入且已授予访问权限的匹配页面中加载，即使尚未启动动画，也会随鼠标移动覆盖当前标签页内存中的最新坐标；不保存移动历史。用于机器人出发和收拢定位。 |
| 页面布局、可访问文本及样式 | 用户通过快捷键启动后，用于生成重建任务及视觉覆盖层；可能包括页面显示的个人信息。 |
| 表单显示状态 | 重建可能读取普通输入框的当前值、下拉框选中内容和复选框状态。密码输入框的专用处理会读取其值的长度并生成圆点占位，不以明文绘制；这不意味着整个页面截图已经过敏感信息脱敏。 |
| 当前标签页可见区域截图 | 当启动检查发现可见的 canvas、视频或嵌入媒体时，尝试临时隐藏非媒体内容并截取可见标签页，供媒体区域裁切重建使用。截图可能包含页面可见的敏感信息。 |
| 媒体引用和当前帧 | 用于显示原页面图像、canvas 与视频当前画面；视频绘制跟随原播放器，不要求上传视频。 |
| 标签页标识与窗口标识 | 后台根据当前活动标签页执行注入与截图，不读取浏览历史列表。 |

动画覆盖层启动前可能短暂滚动页面，以触发懒加载。此操作也可能触发网站自身的加载或统计逻辑。

## 数据存放与保留

- 页面蓝图、截图、动画状态和最新鼠标坐标存放在当前标签页的内存中，不写入扩展专用的持久化存储。
- 当前代码不使用 `chrome.storage`、`localStorage`、`sessionStorage`、IndexedDB 或 Cookie 保存这些数据，也不主动将截图下载到磁盘。
- 动画退出时会移除覆盖层并停止本次动画相关监听；用于后续启动的鼠标追踪监听仍可继续运行。
- **退出动画不保证立即清空全部内存数据。** 当前实现可能保留最近一次截图，以供同一标签页内后续播放复用；最新鼠标坐标和会话入口也可能继续存在。刷新或关闭对应页面后，这些页面内存数据随页面上下文被清理。
- 浏览器自身的资源缓存、内存管理及网站自己的数据保留行为不由本扩展控制。

## 网络行为与第三方资源

当前代码没有用于上传页面内容的 `fetch`、XMLHttpRequest、WebSocket、Beacon 或分析服务请求，不加载远程可执行代码。

重建图像、背景、字体、SVG 引用等内容时，浏览器可能重新请求原网页已经引用的资源；这些请求可能访问原网站或其第三方资源提供方，并遵循浏览器和网站的缓存、Cookie、引用来源及跨域规则。原网页和原视频也可能继续产生自身网络请求。因此，本扩展不承诺“使用过程中绝无网络请求”。

## 权限说明

| 权限或声明 | 用途 |
| --- | --- |
| `activeTab` | 用户触发快捷键后，对当前活动标签页进行相应操作，并在需要时截取该标签页的可见画面。 |
| `scripting` | 注入动画脚本、检查页面媒体，并临时插入或移除截图辅助样式。 |
| `content_scripts.matches: <all_urls>` | 声明在浏览器允许并已授权的网站范围内加载鼠标追踪脚本；该脚本在动画启动前也可运行。不是完整页面重建自动启动的开关。 |
| `web_accessible_resources` | 允许页面中的动画覆盖层加载随插件打包的机器人爆炸 GIF；不用于数据上传。 |

文件网址和无痕窗口是否允许访问，取决于浏览器中对应的扩展设置。浏览器受保护页面可能禁止注入。

## 音频与设备访问

机器人音效通过 Web Audio API 在本机合成，不录音，不调用麦克风、摄像头或地理位置权限，也不读取剪贴板。声音开关不控制原网页自身的媒体播放。

## 用户控制

- 使用启动快捷键决定是否开始页面重建；按 Esc 或再次按启动快捷键可提前退出。
- 在扩展详细信息中调整网站访问范围、文件网址和无痕窗口权限。
- 刷新或关闭页面，清除对应页面的注入脚本和内存状态。
- 在扩展管理页停用或移除插件；对已经打开的页面，再刷新一次以清理已注入内容。
